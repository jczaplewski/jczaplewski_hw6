# 🔧 Git & GitHub Practice Project (HW6)

## Overview
This project was completed for **BAIS:3300 – Digital Product Management** to practice using Git and GitHub for source code management. The focus of the assignment was learning how to create repositories, manage branches, commit changes, merge feature branches, and tag releases using GitHub Desktop.

This project is not about building a complex website, but about understanding how Git tracks changes and manages project history.

## Project Structure

jczaplewski-hw6/
- index.html
- css/
  - stylesheet.css
- README.md
## Assignment Objectives
1. Create a local Git repository and connect it to GitHub
2. Commit and push changes to the main branch
3. Create and work with feature branches
4. Merge feature branches into main
5. Delete local branches while retaining remote history
6. Tag commits to mark project milestones
7. Practice cloning repositories using GitHub Desktop

## How to Run
Clone the repository:
git clone https://github.com/yourusername/hawkid-hw6.git
Open the project folder.

Double-click index.html to view the page in a web browser.
